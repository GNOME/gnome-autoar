# gnome-autoar
A library to provide GObject-based abstractions for archive handling, based on [`libarchive`](https://github.com/libarchive/libarchive/).

## Documentation
The API documentation can be found [here](https://gnome.pages.gitlab.gnome.org/gnome-autoar/)

## Build, Install & Test
Use the default meson build commands `meson compile`, `meson install`, and `meson test`.

## Used By
Designed for GNOME applications. Used by:
* [nautilus](https://gitlab.gnome.org/GNOME/nautilus/)
* [gnome-shell](https://gitlab.gnome.org/GNOME/gnome-shell/)
